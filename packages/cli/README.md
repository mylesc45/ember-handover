# ember-handover

> Early preview (M0). Commands are stubs; nothing runs against your app yet.

Handoff adds a Figma-style Dev Mode on top of any web app's running dev server: exact specs, click-to-source links, end-to-end flows and a guided tour of what changed. It never edits your app, never ships to production and never sends code off your machine.

```bash
npx ember-handover@next --help
```

Source, security policy and roadmap: https://github.com/mylesc45/ember-handover
